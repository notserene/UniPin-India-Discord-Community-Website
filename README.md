# UniPin India - Community Website

Frontend portal for UniPin India's community events, tournaments, and giveaways. Built with React, Vite, and Tailwind CSS.

> The website was developed by adapting one of the projects originally created by `@roy_avi_09`.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

The output will be generated in `dist/`, which can be served by any static hosting provider (Vercel, Netlify, Cloudflare Pages, GitHub Pages, Render).
